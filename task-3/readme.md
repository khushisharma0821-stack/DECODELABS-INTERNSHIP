# AI Recommendation System

## Project Overview

This project is a simple AI Recommendation System developed during the DecodeLabs Artificial Intelligence Internship.

The system recommends movies based on the user's preferred genre using rule-based matching.

## Features

- Takes user input
- Matches preferences
- Displays recommendations
- Uses Pandas for data handling

## Technologies

- Python
- Pandas

## Dataset

Custom Movie Dataset

## How to Run

```bash
pip install -r requirements.txt
python recommendation.py
```

Image and Text Recognition
This project is a simple Python-based Image and Text Recognition system. It uses Pillow (PIL) for image processing, Matplotlib for displaying images, and Pytesseract OCR to extract text from images. The application also displays image properties such as width, height, format, and color mode. This project is useful for learning the basics of image processing and Optical Character Recognition (OCR).
Features
Load and display images
Extract text from images using OCR
Show image details (width, height, format, mode)
Easy to understand and beginner-friendly
Technologies Used
Python
Pillow (PIL)
Matplotlib
Pytesseract
OpenCV
How to Run
Install the required libraries:
pip install pillow matplotlib pytesseract opencv-python
Install Tesseract OCR and set its path in the code.
Place your image as sample.jpg.
Run:
python image_recognition.py
